Commands & flags

Global binary: exm-cli. Package name: express-modular-cli.

exm-cli new

exm-cli new [project-name] [options]

Writes a new directory in the current working folder. Fails if the name already exists.

exm-cli new my-api
exm-cli new my-api --yes --dry-run --no-git --no-install
exm-cli new my-api --yes --orm drizzle --database sqlite
exm-cli new my-api --yes --mongo --auth --module product

exm-cli generate (g)

exm-cli generate <type> <name> [options]
exm-cli g <type> <name>

Must run inside a valid project (see validation).

exm-cli g module user
exm-cli g controller product
exm-cli g module ticket --dry-run

Flags

FlagDescription
-h, --helpShow help.
--dry-runPrint plan only; no writes, git, or install.
-y, --yesSkip interactive prompts; use defaults.
--orm <name>none, mongoose, prisma, drizzle
--mongo / --no-mongoShorthand for Mongoose on/off.
--database <name>postgres, mysql, sqlite (Prisma/Drizzle)
--postgres <host>supabase or local
--auth / --no-authJWT auth, user, and admin modules (any ORM with a database).
--module <name>Starter Mongoose module.
--port <n>Default 1337.
--git / --no-gitInitialize git repository.
--install / --no-installRun npm install after scaffold.
Constraints: JWT needs --orm other than none. Starter --module requires Mongoose. Database flags apply only to Prisma or Drizzle. Supabase options apply only when --database postgres.
