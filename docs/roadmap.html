Roadmap

Planned improvements. Order may change. Track and propose work on GitHub issues.

Templates & architecture

  • NestJS-style optional template — Modules with decorators (@Module, @Controller, @Injectable) and HTTP decorators (@Get, @Post) while still running on Express.
  • Lightweight decorator routing — Class controllers with a small registry, without a full DI container.
  • cli.json profiles — Configurable paths, naming, and default schematics.
  • Template packs — REST, CQRS sketch, or service stubs installable at new time.

Data & auth

  • Module generators for Prisma and Drizzle (today: Mongoose only for g module).
  • Additional auth patterns beyond JWT + Mongoose.
  • Richer Supabase onboarding in generated READMEs (migrations, RLS pointers).

Developer experience

  • Test schematics (controller/service tests).
  • OpenAPI export from route modules.
  • exm-cli doctor for Node version, aliases, and env checks.
  • Stable JSON output for --dry-run in CI and agents.

Recently shipped

  • Local scaffold (no template repository clone).
  • Interactive new, --dry-run, and flag-based setup.
  • Mongoose, Prisma, Drizzle; Supabase Postgres and optional MCP config.
  • Zero runtime dependencies in the CLI; plain JavaScript distribution.
