Roadmap

Planned work. Order and scope may change. Track issues on GitHub.

Architecture and templates

  • NestJS-style optional template — Generate modules with decorators (@Module, @Controller, @Injectable) and route decorators (@Get, @Post) while staying on Express under the hood, for teams that want that ergonomics without switching frameworks.
  • Decorator-based routing (lightweight) — Smaller alternative: class controllers with method decorators and a single registry, without a full Nest-like DI container.
  • cli.json project profile — Custom module paths, file naming, and which schematics run by default instead of hard-coded src/app/modules.
  • Template packs — Installable template bundles (REST only, CQRS sketch, microservice stub) selected at new or via exm-cli template add.

Data and auth

  • Prisma and Drizzle module generators (not only Mongoose g module).
  • Optional auth strategies beyond JWT + Mongoose (session, OAuth hooks).
  • Better first-run docs for Supabase (migrations, RLS pointers) in generated README.

Developer experience

  • Schematics for tests (controller/service tests with a chosen runner).
  • OpenAPI export from route modules.
  • exm-cli doctor — Check Node version, #app imports, and env vars.
  • Non-interactive CI mode improvements (stable JSON plan output for agents).

Done recently

  • Local project scaffold (no template git clone).
  • Interactive new and --dry-run.
  • Mongoose, Prisma, and Drizzle; Supabase Postgres + optional MCP config.
  • Plain JS CLI with zero runtime dependencies.
