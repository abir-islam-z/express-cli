Build modular Express APIs without the boilerplate hunt

express-modular-cli gives you exm-cli: interactive project setup, optional Mongoose / Prisma / Drizzle, module generators, and TypeScript that runs on Node without a compile step in dev. The CLI ships with zero runtime dependencies. 

npm install -g express-modular-cli

What you get

  • Layered modules under src/app/modules with controller → service → model flow
  • Global error handler, Zod errors, and optional Mongoose / JWT handlers
  • Health route, Helmet, CORS, and cookie parser wired in app.ts
  • Generators that update src/app/routes/index.ts when you add a module
  • Cursor agent skill in every new project for consistent CLI usage
Tip: Run exm-cli new my-api --dry-run to preview every file before anything is written. Use --yes in CI or with agents so prompts are skipped.
