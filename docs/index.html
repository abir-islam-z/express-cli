Overview

express-modular-cli installs the exm-cli command. It scaffolds Express.js projects with a modular folder layout, TypeScript run on Node (no compile step in dev), and generators for modules and single files. The CLI has no runtime npm dependencies.

Install

npm install -g express-modular-cli

Node.js 18+ to run the CLI. Generated apps require Node.js 22.18 or newer.

Create a project

With a terminal attached, exm-cli new asks which options you want. Use flags to skip prompts.

exm-cli new my-api
exm-cli new my-api --yes --dry-run
exm-cli new my-api --yes --mongo --auth --module product
exm-cli new my-api --yes --orm prisma --database postgres --postgres supabase

Data layer

Option Notes
None API shell, health route, global error handler.
Mongoose MongoDB. JWT auth and g module use Mongoose models.
Prisma PostgreSQL, MySQL, or SQLite. Includes schema and client stub.
Drizzle Same databases with drizzle-kit scripts.

For PostgreSQL with Prisma or Drizzle you can pick local Postgres or Supabase. Supabase can add Cursor MCP config files; you still fill connection strings in .env from the dashboard.

Generate components

Run inside an existing project directory:

exm-cli g module user
exm-cli g controller user
exm-cli g module ticket --dry-run

Types: module, controller, service, model, route, validation, interface (short aliases: mo, c, s, m, r, v, i).

Project layout

src/
  app/
    modules/<name>/
    routes/index.ts
    middlewares/
    config/
  app.ts
  server.ts

Cross-folder imports use #app/... (mapped in package.json). Same-folder imports stay relative with a .ts extension.

Dry run

--dry-run on new or generate prints files and commands without writing, running git, or installing packages.
