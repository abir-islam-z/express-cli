Schematics

Each schematic adds a file under src/app/modules/<name>/ unless noted.

module

Runs all schematics below and updates the route index.

exm-cli g module user
  • user.controller.ts — CRUD handlers with catchAsync and sendResponse
  • user.service.ts — business logic layer
  • user.model.ts — Mongoose schema (Mongoose projects)
  • user.route.ts — Express router wired to controller
  • user.validation.ts — Zod schemas
  • user.interface.ts — TypeScript types

controller

HTTP layer: create, read, update, delete stubs with consistent responses and routeParam for Express 5 params.

service

Data access and domain logic, typed against the module interface.

model

Mongoose model and schema. Not used for Prisma/Drizzle projects (edit schema files there instead).

route

REST-style paths bound to controller methods. Register manually or use g module for auto-registration.

validation

Zod objects for body and params, ready for validateRequest middleware in auth-enabled projects.

interface

DTOs and document types shared across service and controller.

Context-aware templates

Inside a project, generated code imports #app/utils/catchAsync and other shared utilities. Outside a project, templates can inline minimal helpers (standalone mode).
