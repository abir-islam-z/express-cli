Getting started

Install the CLI globally, scaffold a project, then generate features inside it.

On this page

  • Install
  • Create a project
  • Choose a data layer
  • Generate a module
  • Run the API

Install

npm install -g express-modular-cli

Node.js 18+ runs the CLI. Generated projects need 22.18+ for Node’s built-in TypeScript runner.

Create a project

exm-cli new my-api
cd my-api

With a TTY attached, the CLI asks about:

  • Data layer: none, Mongoose, Prisma, or Drizzle
  • Database (Prisma/Drizzle): PostgreSQL, MySQL, or SQLite
  • PostgreSQL host: Supabase or local
  • Supabase MCP config for Cursor (optional)
  • JWT auth and starter module (Mongoose only)
  • Port, git init, and npm install

Skip prompts with --yes and flags. See Commands & flags.

Choose a data layer

LayerUse when
noneYou only need routes, middleware, and error handling.
mongooseMongoDB, JWT auth pack, and g module generators.
prismaSQL with Prisma schema, client, and migrate scripts.
drizzleSQL with drizzle-kit and a schema stub.
 
exm-cli new shop --yes --orm prisma --database postgres --postgres supabase
exm-cli new shop --yes --mongo --auth --module product --no-install

Generate a module

From the project root (Mongoose projects):

exm-cli g module order

This creates controller, service, model, route, validation, and interface files, then registers the route in src/app/routes/index.ts.

Run the API

cp .env.example .env
npm install
npm run dev

For Prisma: npx prisma migrate dev. For Drizzle: npm run db:push. Health check: GET /health.
